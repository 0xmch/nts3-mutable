nts3-mutable

Four effects for the KORG NTS-3 kaoss pad kit, built from Mutable Instruments' open-source Eurorack code: Rings as Resonator, and Clouds as Texture, Texture Stretch and Texture Loop.

This page runs the same C++ as the hardware units, compiled to WebAssembly and played in an AudioWorklet. The pad, knobs and their ranges come from each unit's own header.

Keys
1–4 switch units · H hold · B bypass · arrows and Space on the pad
Links
The address bar always holds the current sound, so you can share it.
